# FoxUnit class libraries

Real Visual FoxPro 9 class libraries (`.vcx`/`.vct`) from [FoxUnit](https://github.com/VFPX/FoxUnit), used to test the
VCX converter. The `.vc2` files are the same libraries as text, produced by FoxBin2Prg (also from the FoxUnit
repository); the tests use them as an independent reference for class names, parent classes and methods.
